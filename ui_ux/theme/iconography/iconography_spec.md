# Iconography Standards

Consistency in icons is critical for a premium look and feel.

## 1. Icon Library
*   **Recommended:** **Lucide Icons** (Web) or standard **Material Symbols Rounded** (Mobile).
*   **Style:** Line/Stroke icons (not filled) for inactive or standard states. Stroke width should consistently be `2px`.
*   **Filled Icons:** Used exclusively for "Active" states (e.g., the active tab in the bottom navigation).

## 2. Standard Sizes
*   `16px`: Inline with small text (e.g., breadcrumbs, tiny tags).
*   `20px`: Standard buttons, list items, input field adornments.
*   `24px`: Navigation bars (top and bottom), standard icon-only buttons.
*   `32px`: Moderate highlights (e.g., file upload zones).
*   `64px+`: Empty states, Error pages.

## 3. Icon Colors
*   Never use raw black/white unless on a contrasting background.
*   Default Resting: `#A1A1AA`
*   Active/Hover: `#FFFFFF` or `#D4AF37`.
