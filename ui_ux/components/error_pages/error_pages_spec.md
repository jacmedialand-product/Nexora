# Error Pages Specification

Full-screen layouts for routing errors or access denials.

## 1. Layout
*   **Background:** Pure Black (`#000000`).
*   **Alignment:** Content centered horizontally and vertically on the screen.

## 2. Typography & Assets
*   **Visual:** A large, stylized number (e.g., "404") or an abstract illustration using the Gold `#D4AF37` and Dark Grey `#1E1E1E` palette.
*   **Title:** Large (`3rem`), White (`#FFFFFF`). e.g., "Page Not Found".
*   **Subtitle:** Secondary Gray (`#A1A1AA`). e.g., "The module you are looking for doesn't exist or has been moved."
*   **Action:** A prominent Primary Gold button: "Return to Dashboard".

## 3. Specific Statuses
*   **403 Access Denied:** Add a padlock icon.
*   **500 Server Error:** Add a wrench or server icon. Provide a "Retry" button.
