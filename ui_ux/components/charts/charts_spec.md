# Charts & Analytics Specification

Crucial for the "School Intelligence & Analytics" module, providing clear data visualizations.

## 1. General Chart Styling
*   **Background:** Charts should be placed inside standard Dashboard Cards (`#1E1E1E`).
*   **Grid Lines:** Keep to a minimum. Use faint dashed lines (`#333333`) for horizontal guides. Vertical guides should usually be hidden.
*   **Axis Text:** Text Secondary (`#A1A1AA`), small font size (`0.75rem`).

## 2. Color Palette for Data Series
When graphing multiple datasets, avoid standard bright primary colors that clash with the dark theme. Use a tailored, muted palette:
*   Primary Data (e.g., Total Students): Primary Gold (`#D4AF37`)
*   Secondary Data: Muted Cyan (`#45B7D1`)
*   Tertiary Data: Soft Purple (`#9B59B6`)
*   Positive/Negative Data: Green (`#10B981`) and Red (`#EF4444`) only when semantics demand it.

## 3. Tooltips
*   **Background:** Pure Black (`#000000`).
*   **Text:** White (`#FFFFFF`).
*   **Border:** `1px solid #333333`.
*   **Shadow:** Subtle glow.
