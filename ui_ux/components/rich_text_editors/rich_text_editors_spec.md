# Rich Text Editors Specification

Required for teachers creating assignments or admins writing school notices.

## 1. Toolbar
*   **Background:** `#1E1E1E` (Card background).
*   **Border Bottom:** `1px solid #333333`.
*   **Icons (B, I, U, Lists, Links):** Color `#A1A1AA`, hover to `#FFFFFF`.
*   **Active Tool State:** Background `#2A2A2A`, Icon `#D4AF37`.

## 2. Editor Body (Text Area)
*   **Background:** `#121212` (Standard input background).
*   **Text Color:** White (`#FFFFFF`).
*   **Padding:** Generous (`16px`).
*   **Placeholder:** Secondary Gray (`#A1A1AA`).
*   **Focus State:** The entire editor container gets a Gold border highlight (`1px solid #D4AF37`).
