# Tooltips & Popovers Specification

Used for displaying brief contextual information without leaving the current screen.

## 1. Tooltips (Hover only, minimal text)
*   **Background:** Solid Black (`#000000`).
*   **Text:** White (`#FFFFFF`), very small font size (`0.75rem`), center-aligned.
*   **Padding:** Tight (`4px 8px`).
*   **Border Radius:** Small (`4px`).
*   **Arrow:** A small triangle pointing to the target element.

## 2. Popovers (Click to open, richer content)
*   Used for things like "Quick Profile View" or a complex filter menu.
*   **Background:** Deep Dark Grey (`#1E1E1E`).
*   **Border:** `1px solid #333333`.
*   **Shadow:** Moderate shadow (`0 10px 15px -3px rgba(0, 0, 0, 0.5)`).
*   **Border Radius:** Medium (`8px`).
*   **Content:** Can contain avatars, small text, and tiny buttons.
