# Toggles & Switches Specification

Used for immediate settings changes (e.g., "Enable Push Notifications", "Dark Mode").

## 1. Container (Track)
*   **Shape:** Pill (`border-radius: 9999px`).
*   **Inactive Background:** Dark Gray (`#333333`).
*   **Active Background:** Primary Gold (`#D4AF37`) or Success Green (`#10B981`) depending on context.

## 2. Handle (Thumb)
*   **Shape:** Circle (`border-radius: 50%`).
*   **Color:** Pure White (`#FFFFFF`).
*   **Shadow:** Subtle drop shadow to lift it off the track (`0 2px 4px rgba(0,0,0,0.2)`).
*   **Animation:** Smooth sliding transition (`0.2s ease`) when toggled.
