# Signature Pads Specification

Required for official digital approvals (e.g., Parent signing a leave request).

## 1. Drawing Canvas
*   **Background:** Pure White (`#FFFFFF`) or a very light gray (`#F9F9F9`) to simulate paper and provide contrast for the drawn signature. This is an exception to the dark theme.
*   **Border:** `1px dashed #A1A1AA`.
*   **Pen Ink Color:** Pure Black (`#000000`) or Dark Blue (`#0F172A`).

## 2. Controls
*   "Clear" button (Secondary outline) positioned below the canvas.
*   "Save/Submit" button (Primary Gold) positioned next to it.
