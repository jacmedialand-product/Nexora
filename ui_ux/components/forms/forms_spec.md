# Forms & Inputs Specification

Forms must be clear, accessible, and fit the dark theme without being too harsh on the eyes.

## 1. Text Inputs
*   **Background:** Very dark gray (`#121212`), slightly lighter than the page background but darker than cards.
*   **Border:** Default state is a subtle gray (`1px solid #333333`).
*   **Text Color:** White (`#FFFFFF`).
*   **Placeholder Text Color:** Secondary Gray (`#A1A1AA`).
*   **Border Radius:** Medium (`8px`).
*   **Focus State:** The border highlights to Primary Gold (`1px solid #D4AF37`) with a faint gold box-shadow/glow.
*   **Error State:** Border becomes Red (`1px solid #EF4444`).

## 2. Dropdowns / Selects
*   Same resting state as text inputs.
*   **Dropdown Menu:** Background `#1E1E1E` (Card color) with a subtle border.
*   **Hover item:** Background `#2A2A2A`.

## 3. Checkboxes & Radio Buttons
*   **Unchecked:** Dark grey box with a `#333333` border.
*   **Checked:** Filled with Primary Gold (`#D4AF37`), checkmark icon in Black (`#000000`).
