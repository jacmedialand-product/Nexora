# Pagination Specification

Required for long data lists (e.g., student directories, fee logs).

## 1. Layout
*   Usually placed at the bottom right of a Data Table card.
*   Includes "Rows per page" dropdown on the left, and page numbers/arrows on the right.

## 2. Number Buttons
*   **Resting State:** Transparent background, text `#A1A1AA`.
*   **Hover State:** Background `#2A2A2A`, text `#FFFFFF`, rounded corners (`4px`).
*   **Active Page:** Background `#D4AF37` (Primary Gold), text `#000000` (Black), rounded corners (`4px`).

## 3. Arrow Buttons (Prev/Next)
*   **Active:** Text `#FFFFFF`.
*   **Disabled (e.g., Prev on Page 1):** Text `#333333`, cursor `not-allowed`.
