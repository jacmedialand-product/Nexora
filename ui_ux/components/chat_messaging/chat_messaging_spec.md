# Chat & Messaging Specification

For the Parent-Teacher communication or Internal Staff messaging modules.

## 1. Chat Interface Layout
*   **Sidebar (Contact List):** Background `#121212`. Hovering over a contact highlights with `#1E1E1E`.
*   **Main Chat Area:** Background Pure Black (`#000000`).

## 2. Message Bubbles
*   **Sent Message (Self):**
    *   Alignment: Right.
    *   Background: Primary Gold (`#D4AF37`) or a dark gold (`#8C6B1A`).
    *   Text: Black (`#000000`) or White (`#FFFFFF`) depending on the gold shade chosen to maintain contrast.
    *   Border Radius: `12px 12px 0 12px` (bottom right corner squared).
*   **Received Message (Other):**
    *   Alignment: Left.
    *   Background: Dark Gray (`#1E1E1E`).
    *   Text: White (`#FFFFFF`).
    *   Border Radius: `12px 12px 12px 0` (bottom left corner squared).
*   **Timestamps:** Below the bubble, very small text (`0.7rem`), `#666666`.
