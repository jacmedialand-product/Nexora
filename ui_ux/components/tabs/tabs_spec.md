# Tabs & Pills Specification

Used for navigating between sub-views within a single page (e.g., switching between "Term 1" and "Term 2" marks).

## 1. Underline Tabs
*   **Container:** Bottom border `1px solid #333333`.
*   **Inactive Tab:** Text color `#A1A1AA`. Transparent background.
*   **Hover Tab:** Text color `#FFFFFF`.
*   **Active Tab:** Text color `#D4AF37`. A solid 2px gold border (`border-bottom: 2px solid #D4AF37`) touching the container's bottom border.

## 2. Segmented Controls (Pills)
Used for smaller, distinct toggles.
*   **Container:** A pill-shaped background (`#121212`), Border Radius `9999px`, internal padding `4px`.
*   **Inactive Pill:** Text color `#A1A1AA`. Transparent background.
*   **Active Pill:** Background `#1E1E1E` (or a faint gold wash). Text color White (`#FFFFFF`) or Gold (`#D4AF37`). Strong shadow to make the pill pop out of the container.
