# Navigation Bar Specification

## Visual Design
Based on the Nexora premium theme, the Navigation Bar must look sleek, utilizing the dark background with high-contrast elements.

### Web (Top Navigation)
*   **Background:** Solid black (`#000000`) or deep glassmorphism (`rgba(0,0,0,0.8)` with backdrop-blur).
*   **Logo:** Positioned on the far left. Must include the Gold 'NK' monogram and "NEXORA" text.
*   **Links:** 
    *   Default State: Text color `#A1A1AA` (Text Secondary).
    *   Hover/Active State: Text color `#D4AF37` (Primary Gold) with an optional subtle gold underline indicator (`height: 2px`).
*   **Call to Action (CTA):** "Get Started" button positioned on the far right.
    *   Background: Gold Gradient or Solid `#D4AF37`.
    *   Text: Black `#000000` for high contrast.
    *   Border Radius: Medium (`8px`).
*   **Other Icons:** Search and Login links should be minimal, keeping the UI uncluttered.

### Mobile App (Bottom Navigation / Drawer)
*   **Bottom Navigation Bar (Student/Parent):**
    *   Background: `#121212` (Surface color).
    *   Active Icon: Gold `#D4AF37`.
    *   Inactive Icon: Gray `#A1A1AA`.
*   **Sidebar/Drawer (Admin/Teacher):**
    *   Background: `#000000`.
    *   Menu items follow the same active/inactive color rules as the top nav.
