# Skeleton Screens Specification

Placeholder blocks shown while data is fetching from the Supabase backend.

## 1. Visual Style
*   **Background:** `#2A2A2A` (Lighter than the `#1E1E1E` card background to stand out).
*   **Animation:** A subtle shimmer effect. A linear gradient moving from left to right (`rgba(255,255,255,0)` to `rgba(255,255,255,0.05)` to `rgba(255,255,255,0)`).

## 2. Shapes
*   **Text Placeholders:** Height `16px` or `24px`, Border Radius `4px`.
*   **Avatar Placeholders:** Circular (`50%`), matching standard avatar sizes.
*   **Image Placeholders:** Large blocks, Border Radius `8px`.
