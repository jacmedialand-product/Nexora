# Star Ratings & Reviews Specification

Used for the Library module (rating books) or generic feedback systems.

## 1. Star Icons
*   **Size:** Medium (`24px`).
*   **Filled Star:** Primary Gold (`#D4AF37`).
*   **Empty Star:** Outlined in Dark Gray (`#333333`) or filled with `#2A2A2A`.
*   **Hover State:** As the user hovers over the stars (e.g., hovering on the 4th star), stars 1-4 should temporarily fill with Gold to indicate the intended selection.

## 2. Average Rating Display
*   Shows the numeric rating (e.g., `4.5`) in large white text (`#FFFFFF`) next to a single Gold Star.
*   Total reviews count displayed in smaller secondary text (`#A1A1AA`) below or next to it (e.g., `(120 reviews)`).
