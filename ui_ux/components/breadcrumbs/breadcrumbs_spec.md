# Breadcrumbs Specification

Crucial for navigating deep ERP hierarchies (e.g., `Academics > Classes > 10th Grade > Mathematics`).

## 1. Typography
*   **Font Size:** Small (`0.875rem`).
*   **Separator:** Right-facing chevron (`>`) or forward slash (`/`), color `#666666`.

## 2. States
*   **Inactive/Previous Links:** Text color `#A1A1AA`. Hovering turns text to White (`#FFFFFF`).
*   **Current Page (Last Item):** Text color Primary Gold (`#D4AF37`) or White (`#FFFFFF`). Font weight slightly heavier (`500`). Not clickable.
