# Tree Views & Nested Lists Specification

Essential for displaying the curriculum hierarchy (e.g., Grade -> Subject -> Unit -> Chapter).

## 1. Indentation & Structure
*   **Indent:** `24px` per nested level.
*   **Connecting Lines (Optional):** Faint left-border lines (`1px solid #333333`) to visually connect children to parents.

## 2. Parent Nodes
*   **Expand/Collapse Icon:** Chevron right (collapsed) and Chevron down (expanded), color `#A1A1AA`.
*   **Text:** White (`#FFFFFF`), slightly bolder (`500`).
*   **Hover:** Entire row background highlights to `#2A2A2A`.

## 3. Leaf Nodes (End items)
*   **Icon:** Usually a document or dot icon to indicate it's an end-item.
*   **Text:** Secondary Gray (`#A1A1AA`), normal weight.
*   **Hover:** Text turns White (`#FFFFFF`).
