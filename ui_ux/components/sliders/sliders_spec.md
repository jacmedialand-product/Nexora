# Sliders & Range Inputs Specification

Used for filtering by ranges (e.g., filtering fees from $100 to $500, or marks from 0 to 100).

## 1. Track
*   **Inactive/Background Track:** Dark Gray (`#333333`), height `4px` or `6px`, rounded ends.
*   **Active/Filled Track:** Primary Gold (`#D4AF37`).

## 2. Thumb (Draggable Handle)
*   **Shape:** Circle (`16px` diameter).
*   **Color:** Primary Gold (`#D4AF37`) or White (`#FFFFFF`) with a gold border.
*   **Hover/Active:** Scale up slightly (`1.2x`) and add a gold glow shadow (`0 0 10px rgba(212, 175, 55, 0.4)`).

## 3. Tooltip (Value display)
*   Appears above the thumb while dragging. Background `#000000`, Text `#FFFFFF`.
