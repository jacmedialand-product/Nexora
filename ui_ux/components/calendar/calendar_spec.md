# Calendar & Timetable Specification

Vital for school scheduling, exams, and attendance.

## 1. Grid Styling
*   **Background:** Deep Dark Grey (`#1E1E1E`).
*   **Cell Borders:** Thin, faint lines (`1px solid #333333`).
*   **Current Day Highlight:** Border or top-bar of the cell in Primary Gold (`#D4AF37`).

## 2. Event Blocks
*   **Background:** 
    *   Exams: Faint red wash (`rgba(239, 68, 68, 0.15)`), Red Text (`#EF4444`).
    *   Holidays: Faint green wash (`rgba(16, 185, 129, 0.15)`), Green Text (`#10B981`).
    *   Standard Classes: Faint gold wash (`rgba(212, 175, 55, 0.15)`), Gold Text (`#D4AF37`).
*   **Corners:** Rounded (`4px`).
*   **Hover State:** Increase opacity of the background wash to `0.25`.
