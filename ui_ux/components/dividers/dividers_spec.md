# Dividers & Separators Specification

Used to visually break up content without adding clutter.

## 1. Horizontal Dividers
*   **Color:** Very subtle Dark Gray (`#2A2A2A` or `#333333`).
*   **Height:** `1px`.
*   **Margin:** Typically `16px` or `24px` top and bottom to ensure breathing room.

## 2. Vertical Dividers
*   Used in nav bars or tightly packed stat rows.
*   **Color:** `#333333`.
*   **Width:** `1px`.
*   **Height:** Usually matches the text line-height (e.g., `24px`).

## 3. Section Headers (Divider with text)
*   A horizontal line with text centered or left-aligned on top of it. Text color `#A1A1AA`, font size `0.875rem`, uppercase.
