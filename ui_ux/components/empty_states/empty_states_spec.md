# Empty States Specification

Displayed when a table has no records (e.g., "No homework today") or a search returns no results.

## 1. Container Layout
*   Centered vertically and horizontally within its parent container.
*   Ample padding (e.g., `48px` top and bottom) so it doesn't feel cramped.

## 2. Visual Elements
*   **Illustration/Icon:** Large, monochromatic or muted gold icon relevant to the context (e.g., an empty box, a magnifying glass). Size `64px`. Opacity `0.5`.
*   **Primary Text (Title):** Semi-bold, White (`#FFFFFF`), `1.25rem`. (e.g., "No Students Found").
*   **Secondary Text (Subtitle):** Regular weight, Secondary Gray (`#A1A1AA`), `0.875rem`. (e.g., "Try adjusting your filters or search terms").
*   **Call to Action:** Optional Primary or Secondary Button directly below the text (e.g., "Clear Filters", "Add New Student").
