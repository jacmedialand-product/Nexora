# Avatars & Profiles Specification

Used to represent students, teachers, parents, and staff.

## 1. Shape & Border
*   **Shape:** Perfect circle (`border-radius: 50%`) or rounded square (`border-radius: 8px`).
*   **Border:** `2px solid #333333` for inactive users, `2px solid #D4AF37` for active/selected users.

## 2. Placeholder Defaults
*   If no image is uploaded, use the user's initials (e.g., "JD").
*   **Background:** Dark Charcoal (`#2A2A2A`).
*   **Text Color:** Secondary Gray (`#A1A1AA`).
*   **Font Weight:** Semi-bold.

## 3. Sizes
*   **Small:** `32x32px` (used in Top Nav or Tables).
*   **Medium:** `48x48px` (used in lists or chats).
*   **Large:** `96x96px` or `128x128px` (used in User Profile 360 page).
