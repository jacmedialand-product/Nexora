# Action Menus (Kebab/Meatball) Specification

The standard "Three Dots" menu for row-level actions in a data table (e.g., Edit, Delete).

## 1. Trigger Icon
*   **Icon:** Vertical ellipsis (kebab) or horizontal ellipsis (meatball).
*   **Color:** `#A1A1AA`, hovers to `#FFFFFF`.

## 2. Dropdown Menu
*   **Background:** Deep Dark Grey (`#1E1E1E`).
*   **Border:** `1px solid #333333`.
*   **Shadow:** Prominent drop shadow.
*   **Border Radius:** `8px`.

## 3. Menu Items
*   **Padding:** `8px 16px`.
*   **Default Item:** Text `#FFFFFF`, Hover background `#2A2A2A`.
*   **Destructive Item (Delete):** Text Red (`#EF4444`), Hover background `rgba(239, 68, 68, 0.1)`.
