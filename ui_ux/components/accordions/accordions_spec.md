# Accordions & Expandable Panels Specification

Used for FAQs, deep nested settings, or compressing long forms.

## 1. Header (Clickable Area)
*   **Background:** `#1E1E1E` (Card background).
*   **Text:** White (`#FFFFFF`), regular weight.
*   **Icon:** A chevron on the far right. Points down when collapsed, up when expanded. Color: `#A1A1AA`.
*   **Hover State:** Background lightens slightly to `#2A2A2A`.

## 2. Expanded Body
*   **Background:** Same as the header (`#1E1E1E`) or slightly darker (`#1A1A1A`) to show depth.
*   **Padding:** Generous inner padding (`16px`).
*   **Border:** A subtle separator line (`1px solid #333333`) between the header and the body when expanded.
