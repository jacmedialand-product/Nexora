# Layout Grids Specification

Standardizing spacing and structural alignment across the platform.

## 1. Grid System (Web)
*   **Columns:** 12-column grid structure.
*   **Gaps:** `24px` (standard) or `16px` (tight) between columns.
*   **Max Width:** `1440px` for ultra-wide monitors, centering content beyond that.

## 2. Page Margins
*   **Web Dashboard:** `32px` padding on all sides of the main content area.
*   **Mobile App:** `16px` padding on the left and right edges.
