# Toolbars Specification

Toolbars are horizontal bars containing actions, typically placed above data tables or rich text editors.

## 1. Structure
*   **Background:** Transparent or matching the parent container (`#1E1E1E`).
*   **Padding:** `8px 16px`.
*   **Border:** Optional bottom border (`1px solid #333333`) to separate from content.

## 2. Elements
*   **Action Groups:** Related buttons should be grouped together with tight spacing (`4px`).
*   **Alignment:** Primary actions (e.g., "Add New") on the far right. Search and filters on the left or center.
