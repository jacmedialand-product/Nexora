# Badges & Tags Specification

Used for quick labeling (e.g., "Class 10A", "Science", "Transport Opted").

## 1. Visual Style
*   **Shape:** Highly rounded (`border-radius: 9999px`) or slightly rounded (`4px`).
*   **Size:** Small font (`0.75rem`), tight padding (`2px 8px`).

## 2. Variations
*   **Subtle Tag:** Background `#2A2A2A`, Text `#A1A1AA`.
*   **Primary Tag (Highlight):** Background `rgba(212, 175, 55, 0.15)`, Text `#D4AF37`, Border `1px solid rgba(212, 175, 55, 0.3)`.
*   **Outlined Tag:** Transparent background, `1px solid #333333`, Text `#FFFFFF`.

## 3. Interactive Tags
If a tag can be dismissed (e.g., an active filter), include a tiny 'x' icon (`#A1A1AA`) that hovers to White (`#FFFFFF`).
